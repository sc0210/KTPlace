1 · Run an experiment

What you do in the console, from picking a design to comparing results. Each step has a command-line equivalent for scripted experiments.

1Pick a design
Choose a benchmark under benchmark/ (ISPD 2005, ISPD 2015, ICCAD04, ISPD02) with the filter box in New run.
2Choose the algorithm and settings
simpl (quadratic + look-ahead legalization) or ntuplace1 (ratio partitioning). Tick verbose for the per-iteration trace, and add KTPLACE_*=value lines to override tuning.
3Start the run
The engine runs in the console container, in its own directory runs/<id>/.
CLI: ktplace benchmark/ISPD_2005/adaptec1 -a simpl -w output/adaptec1
4Watch it work
The phase bar follows the pipeline below; the heartbeat (frames/s, CPU, memory, time since last output) tells a long solve from a hang. The transcript streams live.
5Read the verdict
Detailed HPWL, overlapping pairs, unplaced cells, cells off rows, and PASS/FAIL from the independent placement check.
6Review the pictures
The Animated placement tab plays the run; the gallery has every SVG frame and the HPWL curve; final.png is the finished placement.
7Compare and keep
Run history lines runs up by HPWL and verdict; label the ones that matter. Download the transcript, trace, placed.pl, or everything as a zip.

2 · The placement pipeline

Every run goes through the same stages, in this order (FlowMgr::run in src/kt_flowMgr.cc). Global placement finds good positions; legalization makes them real; detailed placement polishes.

input / report placement stage independent check output
Load the design
Detect the format (Bookshelf .nodes/.nets/.pl/.scl or LEF/DEF) and read cells, nets, rows, fixed macros and fences.
Log: Reading … input from … · phase bar: design loaded
Report the design
Cell, net and row counts, and utilisation — said before placing, because an over-full design cannot be placed legally whatever the placer does.
default
SimPL global placement
Quadratic wirelength (B2B net model, CG solve) alternating with look-ahead legalization that spreads cells out of over-full bins. See the loop ↓
alternative
NTUPlace1 global placement
Recursive ratio partitioning: cut the die and the netlist together until each region holds a few cells.
no — the usual case
Abacus legalization
Snap every cell into a row site with no overlaps, moving each as little as possible (dynamic programming per row).
yes
Multi-row legalization
Cut tall cells out of every row they span, then place the rest around them.
Check: after legalization
An independent pass over the placement: overlapping pairs, cells outside the die, cells outside their fence → PASS / FAIL.
FastDP detailed placement
Local moves that keep the placement legal while cutting wirelength: global swaps, vertical swaps between rows, and local reordering.
Check: after detailed placement
The same independent check again, so a stage that broke legality is caught where it happened.
Pictures and output
Render plots/final/final.png, assemble the animated GIF from the frames, write placed.pl, and print the stage timers.
Log: Placement completed successfully · phase bar: done

3 · Inside SimPL global placement

Minimising quadratic wirelength alone pulls every cell to one point, so each iteration pairs a wirelength solve (a lower bound: short but overlapping) with a spreading step (an upper bound: spread out but longer). Anchors tie the two together and tighten every iteration until the bounds meet. More in docs/simpl.md.

repeat for each iteration
aBuild the net model
Bound-to-bound (B2B): each net becomes springs between its extreme pins and the rest, so quadratic length tracks the real half-perimeter.
bSolve for wirelength
Conjugate gradient on the sparse system, warm-started from the last iterate, with anchor springs pulling toward the last spread positions. → lower-bound HPWL.
cLook-ahead legalization
Bin the cells, find over-full regions, and spread them top-down so each region's cells fit its free area (avoiding macros and respecting fences). → upper-bound HPWL.
dStrengthen the anchors
Raise the anchor weight (α) so the next solve stays closer to the spread positions.
↺ back to a — stop when the gap between the bounds is small enough or the iteration budget runs out

4 · What a run writes

Everything goes under the work directory (-w); in the console that is runs/<id>/.

FileWhat it is
placed.plThe result: every cell's position, in Bookshelf format.
ktplace.logThe transcript: stages, report tables, the verdict.
ktplace_trace.logPer-iteration diagnostics (always written; -v also prints them).
plots/index.htmlGallery of every SVG frame per stage, and the HPWL curve.
plots/final/final.pngHigh-resolution still of the finished placement.
plots/anim/placement.gifThe animated run (unless KTPLACE_ANIM=0).
request.jsonConsole runs only: design, algorithm, overrides and the exact command.

Pass --no-plots to skip every frame and picture; a full ISPD 2005 run otherwise writes on the order of a gigabyte of frames.

5 · Tuning knobs

The engine reads its tuning from KTPLACE_* environment variables, not flags. In the console, put them in Environment overrides; on the command line, prefix the command.

VariableStageEffect
KTPLACE_SIMPL_ITERSSimPLIteration budget for global placement.
KTPLACE_SIMPL_SEEDSimPLSeed for the initial placement; vary it to see run-to-run spread.
KTPLACE_SIMPL_GRIDSimPLDensity bin grid used by look-ahead legalization.
KTPLACE_SIMPL_DENSITYSimPLTarget bin density.
KTPLACE_SIMPL_FENCESSimPL0 ignores fences, to see what the constraint costs.
KTPLACE_NTU_LEAF_CELLSNTUPlace1Stop partitioning once a region holds this many cells.
KTPLACE_ABACUS_MAX_ROW_DISTAbacusHow many rows away a cell may be moved.
KTPLACE_DP_WINDOWFastDPWindow size for detailed-placement moves.
KTPLACE_ANIMOutput0 skips the GIF (frames and the final still are kept).
KTPLACE_FINAL_ZOOMOutputResolution of final.png.
 
KTPLACE_SIMPL_ITERS=25 KTPLACE_SIMPL_SEED=1 \
    ktplace benchmark/ISPD_2005/adaptec1 -w output/adaptec1-25it

The full list: grep -rhoE 'KTPLACE_[A-Z0-9_]+' src | sort -u.
